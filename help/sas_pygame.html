SaS / Shapes & Sprites (sas_pygame)

← Zurück

sas_pygame ist eine einfache Grafikbibliothek (Port von „Shapes and Sprites“), die intern mit pygame arbeitet. Sie ist in dieser IDE bereits integriert.

Wichtig: Zeichnen und Ereignisverarbeitung funktionieren nur, wenn in einer Schleife view.step() aufgerufen wird. Die FPS-Begrenzung ist bereits enthalten: view.step(60) (Parameter optional).
Achtung (Browser kann hängen):
Da sas_pygame intern mit pygame im Browser arbeitet, kann es bei Endlosschleifen oder fehlendem view.step() passieren, dass das gesamte System nicht mehr reagiert.

Wenn auch der Notfall-Reset nicht funktioniert:
  • Browser-Tab neu laden (Strg + R bzw. Cmd + R)
  • Falls nötig: Den Browser-Tab komplett schließen
  • Im Extremfall: Browser neu starten

1) Schnellstart
import sas_pygame as sas

# Hintergrundfarbe als RGB-Tupel (r,g,b)
view = sas.createView(600, 400, (173, 216, 230), "Hallo SaS")

rect = sas.Rectangle(60, 180, 60, 40, "red")

dx = 4
while view.running:
    rect.move(dx, 0)   # Bewegung sichtbar
    rect.turn(6)       # Drehung sichtbar
    print(rect.getCenterX(), rect.getCenterY())

    # Am Rand umkehren
    if rect.getShapeX() < 0 or rect.getShapeX() > 600 - 60:
        dx = -dx

    view.step(60)

view.quit()

3) Farben

Farben kannst du entweder als Name (String) oder als RGB-Tupel angeben.

Farbnamen (String)

Diese Farbnamen stehen zur Verfügung:

"black" "white" "red" "green" "blue"
"yellow" "gray" "orange" "purple" "pink"
"magenta" (weitere Namen werden ggf. nicht erkannt) 
ball = sas.Circle(120, 140, 30, "red")
text = sas.Text(20, 20, "Hallo", "black")
RGB-Tupel

Ein RGB-Tupel hat die Form (r, g, b) mit Werten von 0 bis 255. 

# Hellblau (wie "lightblue") als RGB
view = sas.createView(600, 400, (173, 216, 230), "Farben")

# Orange als RGB
r = sas.Rectangle(50, 80, 200, 120, (255, 165, 0))
Hinweis: Wenn ein Farbname nicht unterstützt wird, kann die Farbe unerwartet sein. Nutze dann besser ein RGB-Tupel.
4) Shape-Objekte

Alle Objekte werden automatisch dem View hinzugefügt.

Rectangle
r = sas.Rectangle(50, 80, 200, 120, "green")
Circle
c = sas.Circle(120, 140, 30, "red")
Ellipse
e = sas.Ellipse(200, 200, 140, 60, "blue")
Text
t = sas.Text(20, 20, "Hallo", "black")
t.setFont(30)
Polygon
p = sas.Polygon([(150,10),(40,100),(140,140)], "yellow")

p2 = sas.Polygon([(150,10)], "orange")
p2.add(-110, 90)
p2.add(100, 40)
Picture (Bildobjekt)

Mit Picture können Bilder wie Shapes verwendet werden. Sie unterstützen alle Transformationen.

Bilddateien müssen vorher in der IDE hochgeladen werden. 
pic = sas.Picture(100, 80, "auto.png")
Sprite (Gruppe von Shapes)
ball1 = sas.Circle(100, 100, 20, "red")
ball2 = sas.Circle(140, 100, 20, "blue")

system = sas.Sprite(ball1)
system.add(ball2)
5) Transformationen

Transformationen verändern Position, Drehung und Größe, ohne die Grundwerte (x, y, width, height) direkt zu ändern.

MethodeWirkung
move(dx,dy)Verschieben
move(distance)Bewegen in aktueller Richtung
moveTo(x,y)Absolute Position
turn(angle)Drehen um Mittelpunkt
turn(x,y,angle)Drehen um Weltkoordinate
turnTo(angle)Absolute Richtung
turnTo(x,y)Auf Punkt ausrichten
scale(sx,sy)Skalieren (Faktor)
scaleTo(w,h)Auf Zielgröße skalieren
flipHorizontal()Horizontal spiegeln
flipVertical()Vertikal spiegeln
reset()Transformation zurücksetzen
clone()Kopie erzeugen
setHidden(True/False)Ein-/Ausblenden
6) Kollision & contains()
intersects(obj)
if ball.intersects(wand):
    print("Kollision!")

Prüft, ob sich zwei Objekte überlappen.

contains(x,y)
if ball.contains(150,200):
    print("Punkt im Objekt")

Prüft, ob ein Punkt im Objekt liegt.

contains(obj)
if rechteck.contains(ball):
    print("Ball vollständig im Rechteck")

Prüft, ob ein Objekt vollständig in einem anderen liegt.
