Pygame in dieser IDE

← Zurück

Pygame läuft in dieser IDE im Browser-Canvas. Damit dein Programm stabil läuft und sich zuverlässig beenden lässt, nutze das Grundgerüst mit main(), init() und handle_events().

1) Grundgerüst: main(), init(), handle_events()

init() initialisiert Pygame, setzt die Fenstergröße und gibt screen und clock zurück. handle_events() verarbeitet Maus, Tastatur und QUIT und gibt running zurück. main() enthält die Hauptschleife.

2) Fenstergröße (Canvas)

In dieser IDE kannst du mit Konstanten WIDTH und HEIGHT arbeiten. Wenn die IDE die aktuelle Canvas-Größe bereitstellt, findest du sie als MAXWIDTH und MAXHEIGHT (z. B. in builtins). In init() kannst du WIDTH/HEIGHT daraus übernehmen.

3) Ereignisschleife & sauberes Beenden
  • Der rote X-Button im Pygame-Fenster löst ein QUIT-Event aus.
  • Fange QUIT in handle_events() ab und setze running = False.
  • Beende am Ende mit pygame.quit().
  • Wenn ein Programm hängt, kannst du es mit 🔄 Notfall-Reset beenden.
4) Muster-Grundgerüst (zum Kopieren)
import pygame
import builtins

# =========================
# Konstanten
# =========================
# (werden in init() ggf. aus MAXWIDTH/MAXHEIGHT überschrieben)
WIDTH, HEIGHT = 800, 500

WHITE = (255, 255, 255)
BLACK = (0, 0, 0)
RED   = (220, 0, 0)
GREEN = (0, 160, 0)
BLUE  = (0, 0, 220)


# =========================
# Initialisierung
# =========================
def init():
    """Einmalige Initialisierung (Fenster, Variablen, Assets)."""
    global WIDTH, HEIGHT

    # Falls die IDE die Canvas-Größe bereitstellt, übernehmen
    try:
        WIDTH = int(getattr(builtins, "MAXWIDTH"))
        HEIGHT = int(getattr(builtins, "MAXHEIGHT"))
    except Exception:
        pass

    pygame.init()
    screen = pygame.display.set_mode((WIDTH, HEIGHT))
    pygame.display.set_caption("Pygame – Grundgerüst")
    clock = pygame.time.Clock()

    return screen, clock


# =========================
# Ereignisse verarbeiten
# =========================
def handle_events(running):
    """Maus, Tastatur und QUIT abarbeiten."""
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if event.type == pygame.KEYDOWN:
            # ESC-Taste beendet das Programm
            if event.key == pygame.K_ESCAPE:
                running = False

    return running


# =========================
# Hauptprogramm
# =========================
def main():
    screen, clock = init()
    running = True

    while running:
        running = handle_events(running)

        # --- update ---
        # Hier kommt die Spiellogik hin

        # --- draw ---
        screen.fill(WHITE)
        # Hier wird gezeichnet

        pygame.display.flip()
        clock.tick(60)

    pygame.quit()


# =========================
# Programmeinstieg
# =========================
if __name__ == "__main__":
    main()
5) Hinweis: Pygame im Browser (pygame-ce)

In dieser IDE läuft Pygame im Browser und basiert auf pygame-ce. Maus und Tastatur funktionieren, aber es gibt im Browser ein paar Einschränkungen im Vergleich zur Desktop-Version:

  • Leistung: Sehr große Fenster oder aufwändige Animationen können langsamer sein.
  • Schleifen: Nutze clock.tick(...), damit der Browser nicht einfriert.
  • Dateien: Bilder/Assets müssen vorher über Dateien hochladen bereitgestellt werden.
  • Canvas-Größe: Die IDE kann MAXWIDTH/MAXHEIGHT setzen. Nutze dann WIDTH/HEIGHT für set_mode((WIDTH, HEIGHT)).
6) Bilder

Wenn du in Pygame Bilder verwenden willst, musst du sie zuerst über den Menüpunkt Dateien hochladen in den Speicher laden. Danach kannst du sie mit ihrem Dateinamen direkt im Programm verwenden.
